# Security Policy

## Supported Surface

Security reports may cover the current `main` branch, published packages sourced from this repository, public schemas, examples, and verification workflows.

Historical examples and archived evidence remain available for provenance but are not independently supported releases.

## Report A Vulnerability

Use GitHub's private vulnerability reporting or Security Advisory flow for this repository. Do not open a public issue containing exploit details, credentials, tokens, private payloads, or customer information.

Include the affected path or package, reproduction steps, expected impact, and the smallest safe proof available. Neura will validate the report against the repository's authority, privacy, and no-downstream-execution boundaries.

## Boundary

This repository contains public proof and integration material. It does not issue production credentials, grant execution authority, or operate downstream tools.
